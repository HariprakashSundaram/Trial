How timing is calculated

Request duration is HAR entry.time (milliseconds), with fallback to the sum of nonnegative timing phases. Total elapsed capture time is the span from the earliest request start to the latest request finish; summed request durations are shown separately because concurrent requests overlap. The same endpoint called multiple times in one file is aggregated by average duration; call count and maximum duration are also available.
